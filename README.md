# Fundamentos de Desarrollo Web — Flowbit

Repositorio oficial del curso introductorio de desarrollo web para estudiantes de secundaria, elaborado por el equipo Flowbit de la Universidad Peruana de Ciencias Aplicadas.

## Descripción

Este curso enseña los fundamentos de HTML y CSS a través de 6 lecciones cortas en video. No requiere instalar ningún programa: todo se trabaja directamente desde el navegador.

- **Duración total**: ~43 minutos
- **Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación
- **Herramientas necesarias**: Solo un navegador web (Chrome, Firefox, Safari o Edge)
- **Editor en línea**: [JSFiddle](https://jsfiddle.net)

## Cómo usar este repositorio

1. Abre el archivo `course-plan.md` para ver la secuencia completa del curso con los enlaces a cada video y actividad práctica.
2. Los archivos en `starter-files/` son el punto de partida para cada ejercicio práctico.
3. Los archivos en `completed-examples/` muestran el resultado esperado al finalizar cada lección.
4. Los archivos en `scripts/` contienen los guiones utilizados para grabar cada video.

## Configuración para contribuir

No se requiere instalar nada. Para editar el código de los ejemplos:

1. Abre [JSFiddle](https://jsfiddle.net)
2. Copia el contenido del archivo correspondiente en `starter-files/`
3. Pégalo en el panel HTML o CSS según corresponda
4. Haz clic en **Run** para ver el resultado
