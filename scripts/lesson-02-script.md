## ¿Qué es una etiqueta HTML? (0:30 – 1:30)


HTML funciona con etiquetas. Una etiqueta es una palabra especial entre corchetes angulares.


Por ejemplo: `<h1>` es la etiqueta de título principal.


La mayoría de etiquetas tienen una de apertura y una de cierre:


```html
<h1>Este es mi título</h1>
```


La etiqueta de cierre lleva una barra diagonal antes del nombre.


---


## Estructura básica de un documento HTML (1:30 – 3:00)


Todo documento HTML sigue esta estructura:


```html
<!DOCTYPE html>
<html>
  <head>
    <title>Mi página</title>
  </head>
  <body>
    Aquí va el contenido visible
  </body>
</html>
```


- `<!DOCTYPE html>` le indica al navegador que es un documento HTML moderno.
- `<head>` contiene información sobre la página, como el título que aparece en la pestaña del navegador.
- `<body>` contiene todo lo que el usuario verá en pantalla.


---


## Etiquetas de texto (3:00 – 4:30)


Las etiquetas más usadas para texto son:


- `<h1>` a `<h6>`: títulos de diferente tamaño. `<h1>` es el más grande, `<h6>` el más pequeño.
- `<p>`: define un párrafo de texto.


Ejemplo:


```html
<h1>Hola, soy Alex</h1>
<h2>Estudiante de secundaria</h2>
<p>Esta es mi primera página web.</p>
```
